# Student Marks Analysis Project

## Project overview
This beginner-friendly Python project analyzes student marks using NumPy, Pandas, and Matplotlib.

## Files
- `student_marks_analysis.py` — complete Python program
- `student_marks.csv` — sample marks dataset (10 students, 5 subjects)
- `student_analysis_report.csv` — generated when you run the program
- `student_percentages.png`, `subject_averages.png`, `pass_fail_pie.png` — charts generated by the program

## Requirements
Python 3.9+ recommended, with:
- numpy
- pandas
- matplotlib

Install libraries:
```bash
python -m pip install numpy pandas matplotlib
```

## How to run
1. Keep `student_marks_analysis.py` and `student_marks.csv` in the same folder.
2. Open a terminal in that folder.
3. Run:
```bash
python student_marks_analysis.py
```
If you use Jupyter Notebook or Google Colab, upload both files and run the code. In Colab, install the libraries only if needed.

## Features
- Loads marks from a CSV file with Pandas
- Calculates total, percentage, average, grade, pass/fail result, and rank
- Uses NumPy for summary statistics
- Uses Pandas for subject-wise analysis
- Creates three charts using Matplotlib
- Exports the analysis to `student_analysis_report.csv`

## Rules used
- Each subject is out of 100.
- A student passes only if they score at least 35 in every subject.
- Grade bands: A+ >= 90, A >= 80, B >= 70, C >= 60, D >= 35, F < 35.
These rules are illustrative and can be changed to match your college's criteria.

## Suggested project conclusion
The program summarizes student performance, identifies the highest-scoring student, compares subject averages, and displays the pass/fail distribution. The results can help teachers identify strong performance and subjects where students may need additional support.

Note: The included student names and marks are sample data for practice, not real student records.
